# JRK IOS - Viktor Huygebaert

**IMPORTANT**

This app is based on the API which I wrote last year during my course web-services. The API itself is hosted on [render.com](https://www.render.com), using their free plan. This means that the first request performed can take up to 90 seconds. **Keep this in mind when first using the app**.

The api which I wrote can be found [here](https://github.com/ViktorHuygeb/jrk-api) and was designed to assist my youth movement in keeping track of their planned activities, enrolled members and animators.

The app was designed for IOS 16, and is incompatible with any older version.
